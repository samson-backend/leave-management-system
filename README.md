# Employee Leave Management System

A Java console application that simulates a real-world HR leave management platform. This project demonstrates core software engineering principles, including data persistence, business logic validation, and modular design.

## 🚀 Features
- **Employee Management**: Add employees with unique IDs, departments, and annual leave balances.
- **Leave Request Workflow**: Employees can request leave (Vacation, Sick, Emergency) with date ranges.
- **Manager Approval System**: Managers can view, approve, or reject pending requests.
- **Real-time Balance Tracking**: Automatically calculates and updates remaining leave days.
- **Data Persistence**: Saves and loads data to local files so information isn't lost when the app closes.

## 🛠️ Tech Stack
- **Language**: Java
- **Concepts**: ArrayLists, File I/O, Object-Oriented Programming, Error Handling

## ▶️ How to Run
1. Compile all files: `javac *.java`
2. Run the main application: `java LeaveManagementSystem`
